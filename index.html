What it is

Every intruder goes looking for credentials.
So give them some.

Most breaches are found weeks after the fact. SIGBREACH shortens that by planting bait: fake systems, and credentials to those systems that you scatter through the places an attacker goes looking once they're inside. Your own software never uses those credentials, so any use of one is worth waking up for.

There is no baseline to learn and no threshold to tune. A legitimate user has no reason to ever touch a decoy. So when a token gets used, it isn't an anomaly score or a maybe — it's a breach, and you know exactly which system leaked it.

How it works

  1. 01

    Deploy decoys

    Provision real infrastructure — cloud accounts, decoy servers, databases. Indistinguishable from production, connected to nothing.

  2. 02

    Mint tokens

    Generate credentials bound to each decoy. Every token is traceable back to the exact place you put it.

  3. 03

    Leak them

    Plant tokens across your estate — config files, repos, shared drives, wikis, laptops. Bait wherever an intruder would rummage.

  4. 04

    Get the call

    The instant a token is used, SIGBREACH alerts you by email or SMS with the forensic detail: what was used, from where, when.
